RSS isn't extinct.

A quiet place to read the sites you love. No feed deciding what you see, no notifications, no endless scroll. Just what they wrote, waiting for you.

Download View on GitHub

Read in peace, smartly.

  • It finds the folder.

    Make your own folders once. Every site you add after that goes into the one of yours it fits best.

  • It filters the noise.

    Tell each feed what you want to see and what you don’t, in your own words. The rest stays out of your list.

  • It keeps what matters.

    Star an article to keep it close. Your starred list is one click away, and filters never touch it.

Just the words.

Articles open in a clean column with the site’s own words and images. When you want the original page, it’s one key away.

Your reader, your way.

  • Desktop, web or terminal.

    A desktop app, a self-hosted web version, or the command line. Scripts and AI agents can use the CLI too (feedrsauros add …), and whatever they add shows up in the app right away.

  • Keyboard shortcuts.

    J and K to move, S to star, M to mark read, V to open the original. Or just use the mouse.

  • No account, local, open source.

    Everything stays on your machine, and the code is on GitHub for anyone to read.

  • Leave any time.

    Import and export your subscriptions as OPML, so moving in or out takes a minute.

Or self-host the web version

Run it on a home server and read from any browser. It’s one container.

git clone https://github.com/dielduarte/feedrsauros.git
cd feedrsauros
docker compose up -d

Then open 127.0.0.1:7777.
